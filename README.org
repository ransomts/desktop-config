My Linux desktop: a Hyprland session whose whole shell (bar, launcher, notifications, lock screen, control panel, wallpaper, settings) is written in Quickshell, plus the scripts and user services that hold it together. It runs on Pop!_OS 24.04 on a System76 Lemur Pro, docked to four screens most days, with COSMIC still installed as the fallback session.

This is a copy of my real config, published so people can read it and borrow from it. It is not an installer: paths, screens, the keyboard layout (Dvorak) and a few integrations are mine. Take the pieces you want.

* Layout

Everything under =home/= sits where it lives in =$HOME=.

| Path | What it is |
|------+------------|
| =home/.config/hypr/= | Hyprland 0.57 config in Lua (=hyprland.lua=, =layouts.lua=), plus hypridle, hyprlock, hyprpaper, hyprsunset |
| =home/.config/quickshell/= | The shell: about 160 QML files, 15 shaders, a few JS helpers and assets, and its tests |
| =home/.local/bin/= | Scripts the bar, launcher and key bindings call, and the test suites (=*-test=) |
| =home/.local/share/hypr-strict-resize/= | A small Hyprland plugin (C++) for resizing tiled windows, with its tests |
| =home/.local/share/desktop-tests/= | Shared fixtures and helpers for the test suites |
| =home/.config/palette/= | The colour-plan tool's data: master copies of every themed file and alternate plans |
| =home/.config/fuzzel/=, =ghostty/=, =gtk-3.0/=, =gtk-4.0/=, =qt5ct/=, =qt6ct/= | Matching colours for the launcher fallback, terminal, GTK and Qt apps |
| =home/.config/systemd/user/= | User services and timers for the desktop (theme by time of day, polkit prompt, dock layout, logging) |
| =home/.config/uwsm/=, =environment.d/=, =.local/share/wayland-sessions/= | Session start-up through uwsm |
| =screenshots/=, =docs/keybindings.org= | Generated by =desktop-shots=; not edited by hand |

* Versions

- Hyprland 0.57 (Lua config; the old =.conf= format is ignored by this version)
- Quickshell 0.3.2, installed through Nix and run with nixGL (=quickshell-start= handles that)
- uwsm for the session ("Hyprland (uwsm-managed)" at the greeter)
- Nerd Fonts for the bar glyphs, Papirus icons with orange folders (=papirus-orange-install=), Bibata cursor (=bibata-cursor-install=)

* Key bindings in brief

One meaning per modifier, written at the top of the key section of =hyprland.lua=:

| Keys | Meaning |
|------+---------|
| Super | open or go to something |
| Super+Shift | the same key the other way round: send there, reverse, variant |
| Super+Ctrl | adjust: window sizes (arrows, =\= to reset), theme T, mic M, webcam W, colour picker C, recording R |
| Super+Alt | tab groups |
| Super+Z, then a letter | lecture tools: D draw, L spotlight, K show keys, Z the menu |

Some fixed points: Super+D launcher, Super+Tab overview, Alt+Tab window switcher, Super+C control panel, Super+N notifications, Super+I dashboard, Super+W wallpaper menu, Super+comma settings, Print screenshot editor, Super+[0-9] desktops, Super+P display switching. Super+/ shows the live list; the full table is in [[file:docs/keybindings.org][docs/keybindings.org]].

* hypr-strict-resize

A Hyprland plugin that makes resizing tiled windows follow the pointer and the arrow keys literally: Super+Ctrl+Right always makes the focused window wider, whatever side its neighbour is on, and dragging a border moves only that border. It also adds drag-to-place with a preview outline (=DropPreview.qml= draws it). Build with =build.sh= after every Hyprland update; =tests/README.org= explains how to test it in a nested Hyprland without disturbing the live session.

* Using pieces of it

- Copy a file or folder into the same place under your =$HOME=; nothing here needs to be installed as a whole.
- Scripts assume =~/.local/bin= is on =PATH=, and some call each other.
- Things that are mine and will need changing: monitor names and positions in =hyprland.lua= and =dock-monitor-layout= (the serial numbers in the =desc:= rules are placeholders here, so put your own monitors in), the Dvorak layout, mail folder names in =dashboard-data= and =shell-status=, the latitude and longitude for the sky and weather, and the System76-specific bits (=charge-profile=, power profiles, the Fn-row keys).
- A few pills read from things I run locally (a Matrix bridge for Teams unread counts, mbsync mail, an Org calendar export, two Bluetooth video lights). They hide themselves when there is nothing to read.

* How the screenshots are made
:PROPERTIES:
:CUSTOM_ID: how-the-screenshots-are-made
:END:

=desktop-shots= starts a nested Hyprland on the config in this repo, runs the real shell in it on a 1920x1080 headless screen, and photographs it with =grim=. It runs in a throwaway home directory on private D-Bus buses, with every program the shell might launch replaced by a stub, and feeds it made-up data: a calendar with a teaching day, three notifications, canned weather and mail counts, and two terminals showing files from this repo. Drawing in the editor and with the lecture ink is done with a virtual pointer and keyboard, and the animations are recorded with =wf-recorder= and turned into animated WebP. Nothing from my own session can end up in a picture. The same run writes =docs/keybindings.org= from the nested session's bindings. More in [[file:docs/testing.org][docs/testing.org]].
