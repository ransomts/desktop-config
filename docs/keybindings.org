#+title: Key bindings

Super is the Windows key. Generated from the bindings of a running session by =keybind-sheet --org=; edit the descriptions in =hyprland.lua=, not here.

* Apps

| Keys | Does |
|------+------|
| ~Super~ ~Enter~ | Emacs |
| ~Super~ ~T~ | Terminal |
| ~Super~ ~B~ | Firefox |
| ~Super~ ~E~ | Files |
| ~Super~ ~D~ | App launcher |

* Recording and calls

| Keys | Does |
|------+------|
| ~Super~ ~R~ | Record a region (again: stop) |
| ~Super~ ~Shift~ ~R~ | Record this screen (again: stop) |
| ~Super~ ~Ctrl~ ~R~ | Recording: what to record, sound, webcam bubble, GIF |
| ~Super~ ~Ctrl~ ~Space~ | Push to talk (hold) |

* Shell

| Keys | Does |
|------+------|

* Lecture tools

| ~Super~ ~right-drag~ | Resize window |
